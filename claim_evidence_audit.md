# Claim-to-evidence audit (Phase 14)

Audit of the draft "Beyond the Curated Graph: Multi-Source Evidence Integration and Literature-Grounded Discovery for Pharmacogenomic Adverse Drug Reactions" against the repository code, configuration, and cached result files. Conducted 2026-09-09. No new cluster runs; all checks use existing outputs, the indexed KB snapshot (ClinPGx bulk download, `CREATED_2026-07-05`), and small local scripts (`eval_lineage.py`, inline analyses reproduced in `evaluation_results_or_plan.md`).

**Verdict key**: SUPPORTED (evidence checks out) · PARTIAL (true with material caveats the draft omitted) · UNVERIFIED (cannot be confirmed from available material) · CONTRADICTED (the evidence says otherwise).

## 2. Unresolved items

1. **Label–scorer dependence (row 6).** Whether the 72-pair benchmark influenced scorer weight tuning is undocumented. Treat reported validation as in-development, not held-out.
2. **Shared underlying cohorts.** Document-level lineage was measured (2/96); different publications analyzing the same cohort cannot be detected with cached data.
3. **Axis-assignment accuracy.** The three CONTEXT-DEPENDENT explanations were checked as plausible against the papers' own text, but no labelled set exists for contextual-axis accuracy.
4. **Related work.** Rows 18: requires a literature pass against primary sources before any conference submission.
5. **Digest extraction fidelity.** The SLCO1B1 error shows the digest chain can attach a paper to the wrong drug. Only spot checks were done; a systematic extraction-fidelity audit (sample of digests vs source paragraphs) is proposed in `evaluation_results_or_plan.md`.

## 3. Summary of changes from the previous draft

- Retitled and reframed: central contribution is now **provenance-preserving pharmacogenomic evidence auditing** (contextual disagreement analysis + candidate identification against a specified KB snapshot), not "discovery" or "creativity".
- Contribution list cut from six to three. GenMedGPT pilot, phase history, and composite rankings moved to appendices.
- "Five sources" reframed as **information channels** with measured, partially unresolved dependence; independence claims removed.
- Scoring section now includes the actual equation, all constants, label thresholds, missing-data rules, and the two measured dependence effects.
- "Calibration" → "evidence-score validation"; Spearman/separation denominators stated; **contradiction precision 0.47 reported beside recall 0.95**.
- Candidate list corrected: SLCO1B1 removed (extraction error); MLH1/MSH3 reclassified (endpoint mismatch + drug-class "not associated" rows missed by normalization); CPVL/PIGR reclassified (protein biomarkers); KCNK17 retained with qualifiers. Absence definitions (gene-level vs pair-level vs contextual) defined and used consistently.
- False-premise section rewritten from manual re-adjudication of all 12 phases; regex artifact documented; phase-9 counterexample kills the old causal story; probe described as one diagnostic case.
- "Discovery without hallucination", "correctness is enforced by the ledger", "controls that make discovery safe", "the disagreement dissolves", "ahead of the curators or wrong" — all removed or replaced with statements of what is actually checked.
- Offline inference vs online retrieval distinguished; "env-var-only ablation" downgraded to configuration comparison with the 9 vs 9L pair identified as the controlled one.
- New analyses added (lineage quantification, probe re-adjudication) and two runnable scripts provided; proposed experiments kept out of the manuscript.
